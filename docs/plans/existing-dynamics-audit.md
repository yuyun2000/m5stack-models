## StackChan：真实残余，而非制造认证门槛

本轮重新执行当前无落盘诊断，仍为 `fit-unresolved`：6234个舵机体素采样中有7组部件/原壳穿插，逐组共387个占用样本；它们不是联合体积。涉及motor case、shoulder、gearbox cap和两安装耳对`servo-rear-cover`或`neck-cradle`。Adapter对盖板1500个样本无冲突。穿插双方都归yaw，所以它是持续的静态包装问题，不能以动作通过来消除。

后背本来就是官方开放机构，视线后方存在真实Power PCB，不应封成额外后壳。盖与cradle已由原孔轴及面相对注册，盲目挪盖会破坏该关系；直接缩小舵机、切原CAD或移动已拟合关节轴也不能成为修复。

进一步独立提取实际圆孔边界：当前耳对两组候选固定孔横向误差约0.05mm，但耳面至候选cradle座有约15.85–15.90mm轴向空档；输出轴只进入左臂接收面约0.50mm。将整颗舵机平移去贴这组座面会先拔离左臂。[已提供的舵机尺寸图](https://m5stack-doc.oss-cn-shenzhen.aliyuncs.com/1205/SCS0009.pdf)第6页中的安装耳深度并未发现误读；仍需确认本款实际舵机外形、这组源孔的用途，以及输出面、耳座、左臂与右轴承之间的局部装配关系。一份可信的尺寸链或清晰拆解资料即可，不强制要求完整STEP或BOM。

运行新的无落盘安装诊断：

```sh
node scripts/check-stackchan-servo-mount.mjs
node scripts/check-stackchan-servo-mount.mjs --strict
```

正常命令输出当前几何诊断；`--strict` 对未闭合状态退出2。它保留“这组原孔是耳座”为待确认假设，不能把量测空档解释成已证实的量产装配方式。当前来源没有支持可安全合入的改位，不继续重复刷新已知未更新入口。

同日新发现的[官方预售爆炸图](../research/stackchan-motion-contract/exploded-view-followup.md)已与原生零件轮廓对照：它澄清了 U 件、长板、小片及独立圆环的身份，但未提供量产止挡或耳部紧固尺寸，不能直接用于改位。独立五方向包含复核仍得到一致的七组实体穿插；当前未闭合状态保持。
