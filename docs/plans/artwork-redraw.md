3. 投影到已有真实壳面、固定 PCB 印刷面或对应移动件，保留真实孔与控件运动。
4. 与基线对比组件/API/端口与非印刷实体，检查变体、关闭选项、接线和资源释放。完整 check/build 后在真实浏览器检查每个新增印刷面及代表动作，保存当前证据。
