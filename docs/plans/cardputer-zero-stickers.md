# CardputerZero 侧面及顶部贴纸

2026-10-26；公开基线 `664799e4ec9fbdd7aea3783dfd9f71e82ec7ff81`。

目标：补齐此前暂缓的四片正式栅格贴纸。原表、源链接、矢量和转换中间材料继续仅保存在仓库外私有目录；其他型号结构扩展及 Scroll WIP 保持暂停。

官方正面、两侧及斜视照片交叉表明，当前 CardputerZero 的外围接口沿 X 镜像：从正面看，USB-A/RJ45 端口组应位于左侧，HDMI/音频/Grove 组应位于右侧；顶部 microSD 和红外件也需要同方向校正。当前前盘、键盘、电源及背贴方向保持。

实施顺序：

1. 在旧真实模型上保存方向回归失败，明确当前测试中错误的左右假设。
2. 同步校正外围端口、实际开孔、Boot 帽、顶部槽口与相应内部避让；保留组件 ID、连接器类型、按键动作及外部显示接口。
3. 按正式原稿比例加入接口条、USB/BOOT/LAN 标、GPIO 标与 microSD 标；使用目标实体表面，不镜像源图、不用贴纸堵住接口。
4. 核对开口通路、贴层可见性、按压/回位和实际 Grove 连接；更新接入文档，调用方从 Port 世界变换读取位置，修正先前硬编码坐标。
5. 完整 check/build、当前浏览器逐面检查、隐私及来源边界复审后，才提交公开增量。旧贴纸验收记录保持原快照。

产品仍为照片重建、`modeled`，隐藏件局部尺寸及 WIP 硬件修订继续保留限制，不声明制造配合或电气行为。

已完成：旧真实模型方向/通路回归 21 项失败，修正后 46/46 通过；PCB 和电池保持原件的 X 镜像，未新增退化、反法向或闭合异常。四片原 PNG 共投影到五个实体表面，1332/1332 不透明采样点首先命中贴层；48 个控件动作不带动固定印刷。
