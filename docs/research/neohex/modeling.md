# Unit NeoHEX A045-B

本款没有采用原生CAD。外形来自自身多视尺寸图、清楚前背/侧照、37灯布局和原理图；没有借旧HEX A045或其他Unit换名。

采用毫米、+X右/+Y上/+Z灯面。图纸主体平边距31、六个安装孔中心半径18（上下孔心距36）、六耳外径4/通孔2、PCB厚1、裸装总厚9.55；规格36×36×9.6是独立标称。包含全部耳的实际包络约35.7957×40mm，裸板厚9.55，装独立0.3mm推导厚度的均光片后9.85。meta.size按实际完整包络，不把安装基准当全壳36mm方框。

PCB是真实闭合材料，有六个镀铜安装孔、六个breakaway槽及12个Grove焊脚贯孔/孔壁/焊环。耳孔金属内径保持2mm，方形焊脚与镀孔留正间隙。实际37颗WS2812C-2020-V1按4/5/6/7/6/5/4排布；每颗有固定底座/包封唇、四接点和独立实心RGB封胶体。13个去耦实体及焊端保留在背面。LED/座/电容的具体坐标、厚度、暗部配合及breakaway槽的未标尺寸均是本款照片配准推导，不称制造BOM或量产互配。

从背照看左IN是灯面坐标+X侧：canonical `grove`在+X朝right，`out`在-X朝left，第三个`grove-in`在背面朝back。三个都是本款照片的真实Grove型接收座；J3在原理图通称Header4，不画成裸2.54排针。侧壁/底/深背衬/导轨/四接点/折弯焊脚均为实体，PCB保持支撑。三座可分别接四芯附件，但不传播电源、LED串行数据或级联状态。

`led-1`…`led-37`对应本款布局U1…U37，是普通Led组件，现有demo可逐个设置on/color/brightness。每颗封胶材质独立，外驱一颗不会改变另36颗或其他已接灯板。只实际封胶表面发光，关闭billboard glow，不把灯板当显示屏或模拟WS2812地址/时序/固件。没有虚构按钮、传感值、speaker、matrix或机械关节。

实际随附乳白均光片是独立静态薄片，底面放在37个真实封胶顶面。`Diffuser`导出配合`diffuser`机械放置Port（`m5.neohex.diffuser`）；这是可移除薄片的姿态/所有权API，不声称存在专用插座、卡扣或铰链。`{diffuser:true}`为完整板，`{diffuser:false}`只移去薄片。片厚/透明材质/安装高度是照片推导，非校准光学。移片保留PCB/所有灯/三座/针脚与印刷；`port.detach({dispose:false})`可保留附件后原样装回。

印刷是两张本款官图代码重绘透明PNG，仅投影在固定PCB真实外表面：前面的1…37位置号，背面的可辨M5Stack/IN/OUT/G/5/S/V1.1和方向标。原理图物理U1…U37布局同时提供编号对应；不由此模拟串行地址。不可辨的细小批号不补写，包装功耗卡/宣传箭头不混入。没有照片像素、原矢量或伪造胶膜。字体、白色、字距/位置为外观近似，详见artwork.json。artwork:false只移墨，保全部物理attributes/index/matrixWorld。

必要局部检查结果见smoke.json：417个物理mesh有向闭合/正体积、安装孔/实际槽和镀孔轴线/FrontSide壁、三座深背衬及接点/真实贯板尾针、37灯独立/noecho、均光片支撑/拆装、两入口两配置去墨、变换父节点下三座四芯/嵌套peer、资源释放。未做GPU/浏览器逐面、历史全量、校准光学、生产或实物验收，阶段modeled。新增代码MIT，第三方产品标识与设计保留权利。
