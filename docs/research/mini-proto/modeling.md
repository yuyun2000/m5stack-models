# Unit Mini Proto U064

本款为32×24×8mm迷你万能板，采用自己的官方CAD和官图。坐标+X向右、+Y朝洞板上方、+Z朝裸板。官方STL完整装配source0共3222面全部保留；依据本文件另外摆放的前后壳副本做有向顶点对应，将原装配分成前壳1526面、后壳1696面。只作一次共同平移，不缩放、补面或删面；副本不进入运行模型。两壳各自有向边count-two、正体积，原装配12条重合接缝保持原位。

自己的直拍与斜拍图可数出8列×6行、48个洞，宣传图标出2.54mm孔距。运行模型为有厚度黄色板材、48条金属孔筒和96个双面焊环，每个洞都真正贯穿。1mm自由孔径、1mm板厚、0.03mm镀层和隐藏安装位置为外观重建估计，不作为生产参数。安装孔、中心固定孔、原壳卡件与外形均保留真实材料壁，实际后壳挡在裸板孔后；后壳两个上角的原生凸台也保留。

黑色HY2.0-4P接口包含导向侧壁、锁扣肩、深腔后壁、四根金属针及落在真实PCB和焊盘上的固定端子。原理图P1仅是四线引出逻辑，没有证实量产另装立式排针，因此不额外虚构。没有默认用户电路、按钮、灯、显示器、传感器或机身驱动关节。

`Model`是独立外观入口，`GroveModule`通过现有四芯Grove线装入主机端口。`rearCover:true`默认完整装配；`rearCover:false`仅移除实际后壳、其背标薄膜/油墨和单颗固定件，前框、洞板及接口保持原位。该选项为维护观察，不是铰链或拔板动画。`grove`仅表达接头和姿态，印刷5V及原理图信号名称不建立电气行为。

仅背面存在MINI / PROTO标签，已参照本款清晰官图准确代码重绘为1580×1180普通PNG，静态URL字面量绑定。白底X、黄底X、红底5V、黑底GND依次保留；字体与色彩、注册位置为说明过的估计。前面为裸洞板，不铺虚构贴纸；未辨清的小丝印不猜写。实际物理胶膜与油墨分开，两入口、两种后壳配置中，`artwork:false`均保持全部实体属性、索引及世界矩阵相同。

必要Node验证已通过：原面全保、30种独立材料几何闭合正体积；48孔240条轴线、576条金属孔壁、196条基材孔壁、48条后壳背挡；两安装孔及真实Grove针/深腔；四种入口/后壳配置的印刷不变量；变换父级下四芯线、独立peer、外部命令无input回声、拆装保持姿态和200项资源释放。TextureLoader的真实URL派发与PNG元数据白名单另有检查；实际Vite打包图片由集成阶段核实。未声称GPU、生产装配或实机验收。
