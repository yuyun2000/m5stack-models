# Unit MQ artwork

Four final PNGs are supplied together with the U199 model. The rear schematic/Grove pin print is `source-vector-raster`, converted from the exact-model private original. The visible `Unit MQ` title, blank white hood identification sticker and `MQ-5` collar lettering are `reference-redraw`, drawn in code from this exact product’s own official photos. The empty identification label intentionally carries no invented content. [artwork.json](./artwork.json) records final hashes, dimensions, registration and public photographic references.

The vector conversion retains the actual rear label contour and its print, removes the unrelated separate cutline area by bounding the vector viewBox, and rasterizes at high resolution. A second candidate is only cutting geometry and is not rendered as printed content. No photograph is cropped, projected, sampled or enlarged as a texture.

All four labels project onto existing shell/collar triangles. The native circular sensor opening, mounting bores and Grove mouth remain real; physical PCBs, socket contacts and the complete cartridge exist independently. The collar label belongs to the removable cartridge and follows it. `artwork:false` hides chassis and cartridge prints while preserving physical arrays, indices and world transforms in both installed and bare configurations.

Only ordinary final PNGs are distributed. Private table/mappings, private source URLs and original names, source vectors, original photos/CAD, generators and intermediates remain excluded. Product print, names and marks retain their respective rights. Code redraw font metrics, colorimetry and registration are appearance estimates. Necessary PNG/decode/registration checks passed; browser pixel acceptance and exhaustive review remain deferred.
