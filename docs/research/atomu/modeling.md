# AtomU / K117 原创建模

本款是官方目录中的独立旧款主机，当前标EOL；完整系列覆盖仍包含它。未借其他Atom的CAD换皮。本款官方多视图、裸板正反面、引脚图及机械图是约束，固定Hardware树未找到自身K117结构源，所以明确采用原创完整实体路线。

## 精确外形与实际装配

[官方资料](https://docs.m5stack.com/en/core/AtomU) 的表格和机械图为53×20×10.3mm，其中USB-A外露13mm、壳40mm、R3；旧hero写52×20×10，冲突保留。本地坐标+Y朝Grove、+Z朝正面，整体中心在原点，壳中心Y=6.5，运行尺寸20×53×10.3。主体实际包络射线/Box3专项证实20×53×10.3，微小墨层/贴膜/标志和分模线另有视觉厚度估计。

后底为真厚板，四边厚壁、R3转角和前盖实体相接，保留真实USB根部、Grove、6p及Reset口。主板有连接后底的四支承。USB-A是公头：真实上下金属薄壁、两侧壁、上下四个锁孔、厚介电舌、四金接点、四端子、两固定脚和深根止挡。Grove为四个独立金属针，锁扣、内壁与深止挡均为实体；背侧6p有六个独立深井、十二簧片和焊脚，井内四壁均做真实FrontSide首交。

耳切对多个共线矩形孔会留下T接盖边，因此原创6p外壳分为六个严格相接的闭合井单元，USB金属面每面分成两个严格相接的闭合金属单元；这只是保形分网，不声称真实插座能拆成六件。未减少严格闭合/方向/体积验收来绕过问题。

## 实际U舌、Reset与外驱输出

前盖是含U槽的完整连续闭合实体，U自由端朝+Y、固定根Y=-5.8；连通图隔离396个独立顶点/2198个位置记录，完整内外截面和RGB光缝壁保留。局部动作最大估计行程0.14mm；根与固定邻区不动。真正的受力杆按本款实际内壁三角形重心权重随动，顶端与舌内壁实际首交差小于0.000002mm，停机后position/normal源数组精确恢复。

Reset是独立实体侧帽与受力杆，位于自身厚壁真实开口内，在实体接收孔里运动；内部留正侧隙和深止挡。自然click、双输入同时、各来源叠加/释放和cancel分别测试。固定RGB在真光缝下，麦克风拾音管对齐真实U槽开口，IR被动封装在自身端部真口。主键/Reset不自动改变RGB、音频、IR、电源、固件或启动状态。

RGB仅`led`外驱G27；`button`G39，`reset`为独立输入意图；`grove`GND/5V/G26/G32，`ext-6p`按自身背图标出G21/G22/G33/G25/5V/GND，`usb`为公头视觉机械口。SPM1423、CH552和ESP32-PICO-D4仅物理封装，不虚构音频、总线或传感器数值。
