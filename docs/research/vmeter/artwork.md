# Unit VMeter artwork

Two final PNGs are enabled by default, both `reference-redraw` from this exact U087 product’s official photographs. The front carries + / −, ±36V, the blue V disc and Meter / ISOLATION. The rear carries the printed ADS1115 / CA IS3020S / ISO DC-DC / E²PROM block illustration and Grove pin colors. [artwork.json](./artwork.json) records sources, raster hashes, placement and limits.

The front print uses an adhesive film spanning the native central clip slots, matching the actual installed label. The original slots remain present and the enclosure contains a physical PCB, packages and converter. The rear print projects onto existing native shell triangles. No label fills an external port or mounting bore. `artwork:false` hides both prints without changing physical attributes, indices or world matrices.

The rasters were drawn at150pixels/mm using readable own-model text, linework and color blocks. No photograph pixels are cropped, projected, sampled or enlarged. Font metrics, tiny schematic trace layout and colorimetry are estimates; the print does not execute a circuit. Only ordinary final PNGs are distributed. Raw source artwork, spreadsheets, vectors, links to private originals, generators and intermediate material are excluded. Product print, names and trademarks retain their respective rights.
