# Unit Neco U163

本款按官方 U163 自身六视尺寸图、正背产品照片及原理图参数化建模。未消费 CDN STEP 的任何面，也未借用 HEX、NeoHEX 或其他产品的 PCB/壳体。新代码采用 MIT；产品印刷设计和商标保留各自权利。

## 机械基准

统一坐标为 +X 右、+Y 上、+Z 正面灯珠侧，PCB 位于 z=-0.5…0.5 mm。自身图纸的完整装配为 **47.1×44.6×10.1 mm**；正文 44.6×43×10.1 中的 43 mm 是外侧下孔中心距，不能用来压缩完整外形。43/28 mm 两组孔中心间距、内孔高于外孔中心线 2.6 mm，以及 1 mm 板厚按自身图纸保留。正文与图纸差异已有官方知识反馈 `ff8e146d7d1a49608b4af75abdfd6004`；本模型保留两个基准及解释。

猫耳曲边的两侧三次曲线来自本款图纸外轮廓笔画中心拟合，采样点最大偏差约 0.033 mm；该值只描述图片拟合，不能作为制造精度。顶端圆弧、底边弧度、未标孔径及金属固定眼的孔径/凸缘/后侧高度依照片推导。两个外孔具有贯通金属孔壁；两个内孔有独立的贯板金属眼、正面凸缘和后侧金色固定圈，均保留真实内壁与通孔。未模拟螺纹、材料力学或制造配合。

35 颗真实 2020 RGB 封装沿两侧和尖端分布，各有固定白色基座、开孔唇边、四端金属及独立封胶实体。灯珠中心和角度来自自身正视图；封装高度、封胶轮廓与固定端子厚度为外观推导。17 个去耦电容及其两端焊盘/金属端头依据本款原理图数量和正面照片重建；不虚构 MCU、驱动控制器或无线模块。未复制不可辨的微小批次字、过孔阵列和铜走线布线细节。

背面两个真实直立 HY2.0-4P SMD Grove 接收座都朝 -Z，接点列沿 PCB Y；各自端墙、封闭底/背、锁桥、四接触针、折弯针、板面焊脚/焊盘及两个固定锚片保持实体。后视左输入座在模型 +X，后视右输出座在模型 -X。八个 SMD 焊脚和焊盘实际接到 z=-0.5 的板面，未画成贯板直排针。尺寸图总厚度用于约束灯珠顶 z=1.35 与 Grove 口面 z=-8.75；接收座细部为本款照片推导。

S1 位于本款照片所示后侧边缘，为实际轻触瞬时键。黄色帽及其黑色中心一起运动，独立固定的开孔金属盖、带真实帽井的壳体、封闭底座和四端焊脚留在原位。`travel=0.15 mm` 沿 +Z 压入为外观估计，并非原厂额定行程。商品包装中的第二块相同灯板、任意弯形涂层铁丝不被虚构成左右版本或附加关节；本入口表示一块完整灯板。

## API 与行为范围

导出 `Model`、`GroveModule`、`spec`。唯一真实装配预设为 `{id:'assembled', name:'完整猫耳灯板', options:{}}`，`defaults={}`；没有服务拆盖预设或猜测配件。

- 组件顺序：`grove`、`out`、`button`、`led-1`…`led-35`。Grove 包装入口随后增加现有 `unitFrame`、`cable`，使用实际四芯线及两插头。
- `grove` 是线缆入口；`out` 可接另一个 Grove 实例，仅提供机械占用/连接所有权。没有数据、电源、RGB 状态或按键事件的自动转发。
- `button` 使用现有普通 `Button`，支持 press/release/cancel、多来源保持和回弹；`down/up/click/longpress` 为外部输入意图。顶层 `Model` 的 Space 指向本键。按键不会自动改变任何灯、重启设备或执行固件。
- 35 个普通 `Led` 默认关闭，可用 `host.get('led-1').set({color:'#ff7700',brightness:.6})` 或 `handle({type:'led',target:'led-1',color:'#ff7700',brightness:.6})` 独立外驱。现有 demo 的 `list('led')` 可以逐颗选择；未改 demo。每颗具有独立 `lensMaterial`，发光限制在真实封胶上，billboard glow 保持关闭。
- 灯号只按正视下左端沿边缘经过尖端至右端的可见路径编号，**不声称等于原理图 U1…U35 或 WS2812 串行地址**。不提供 matrix、自动级联/灯效、WS2812 协议、电流功耗、固件或电气仿真。
- 原理图 J2 pin1 未连接，但实物 PCB 底部印字为 BTN。印字按照片保留，接口元数据明确 NC，不由印字推导电气行为。

`necoAssembly` 显式暴露 `board`、`input`、`output`、`control`、`display`。唯一运动实体位于 `control.button.cap`；`control.fixed`、`control.frame`、PCB/金属固定眼、灯封装及所有 Grove 针脚均固定。

## 印刷

两张 **2826×2676 透明 PNG** 为本款清晰照片的代码重绘：正面 17 个电容丝印轮廓，背面 M5STACK、BTN/RGB-IN/5V/GND、GND/5V/RGB-OUT/BTN、箭头及定位点。字形、字号、颜色、间距及对位为照片重建，不冒充原始矢量转换或校色印刷。没有照片裁切、猜测微字或借用其他型号图案。

两张图通过各自静态 literal `new URL`，仅投影到实际 PCB 朝外三角面，四孔和边缘保持真实几何；没有独立胶膜。`artwork:false` 只去墨，两个入口/唯一实际装配的全部物理 attributes、index 和 matrixWorld 均保持一致。原图、SVG、生成器及检查预览均留在非分发工作目录。PNG 只保留数值 DPI，不含文字、EXIF、ICC 或私有来源元数据。

## 必要本地检查

`smoke.json` 记录 410 个物理 mesh、74,536 个三角面、逐件坐标焊接后的有向二计数闭边与正体积、实际包络、四孔 20 条空轴、92 条 FrontSide 内壁/封胶射线，以及 35 颗灯各中心和四个内角共 175 条 PCB 支撑射线。两座封闭背板、四接点和八 SMD 焊脚接板检查通过。35 个独立灯/无输入回响、真实 S1 帽体行程/固定几何不动/多源取消/精确回弹、两个入口去墨不改物理、变换父节点三条四芯线及嵌套 peer 无自动串亮、2152 个资源释放均通过。

阶段为 `modeled / visual-only`。已看离线正背贴字检查图，未做 GPU/browser 验收、实物测量、制造配合、电气或固件验收。
