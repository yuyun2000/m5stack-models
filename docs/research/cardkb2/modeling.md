# Unit CardKB2 · U215

采用本款自身六视尺寸图和正/背/侧照片参数化完整构建，不使用旧 CardKB 几何，不声明官方 CAD 原面。实际 PCB 为 **84×54×1 mm**，四个 Ø2.2 通孔中心组成 **78×48 mm**。自身图纸完整带器件包络 **84.7×54.3×6.15 mm**；正文 1.0 mm 是板厚。加入有真实载体依据、厚度推导 0.04 mm 的背贴后，模型视觉厚度为 **6.19 mm**，两种基准分别记录，没有压扁 Grove 或按键来凑板厚。

本款有 42 个大触觉开关（10+11+11+10），另有板上/下边的侧向 RST、BOOT，共 **44 个真实瞬时控件**。每个大键固定黑色座体有真实中央导向孔、深底、银色盖及四个固定焊脚；只有无字红色圆柱和下部 plunger 随对应 Button.cap 向 −Z 运动。RST 向 −Y、BOOT 向 +Y 内压，只有实际灰色侧 plunger 和下部杆动，黄色盖、金属盖、座体和焊脚不动。0.22/0.16 mm 视觉行程由自身照片推导，不宣称实测止挡/触感。所有字母、符号和键名在固定 PCB 间隙，移动红帽/灰帽没有印字。

`cardkb2Assembly` 保存 PCB/过孔/焊盘、左侧 Grove、真实 USB-C、42 组开关、RST/BOOT、实际 ESP32-C61HF4 QFN40 5×5 mm 包体及固定封装支撑、实际 XL-1615RGBC-RF RGB 和独立背膜。Grove 有四个接触件与四个真实穿板尾脚；USB-C 有闭合金属口、深介质背衬、中央舌片、24 个实际接触片与固定脚。USB 边缘让位使用真实板轮廓，不用跨出外轮廓的假孔；背膜对实际安装孔、服务长孔和 USB 让位真实裁空。

入口导出 `Model/GroveModule/spec/KEYS`。本体组件顺序为 `grove,usb,key-1…key-42,reset,boot,rgb`，四芯 Grove 包装随后增加 `unitFrame,cable`；标准电缆实际输入为 `grove`。只有 `complete {}` 构造预设，无拆盖、铰链或插卡选项。`key-1…42` 是前视四行从左到右的物理编号，`label` 是印字说明，不进行字符、矩阵扫描、Aa/Sym/Fn 组合、复位/Boot 执行或无线/固件行为。44 个 Button 的 press/release/cancel 只产生 down/up/click 意图；多源持有与取消遵循核心 Button 合同。RGB 接受独立外部 on/color/brightness，不回声为 input，也不根据按键变色。

前面 **1 张 reference-redraw PNG** 是按本款清楚官方正照代码重绘的固定 PCB 字符/符号，透明墨层投影到实物 PCB；没有平面图片遮键或印到红帽。背面 **1 张 source-vector-raster PNG** 由本款原始矢量设计在本地转换，保留原字形/配色，附于有真实证据的实体背膜。字体度量和配准、背膜厚度/裁切留位属于推导；不可读微小器件/批次字没有猜造。CSV、矢量、原始名称/链接/映射、生成器、原图和证明图不进入公开树。`artwork:false` 只关闭两块墨层，全部实体和几何属性不变。

必要 smoke 通过：565 个闭合正体积物理网格；28 条空轴、76 条 FrontSide 内壁射线；实际 Grove 四尾脚/USB 24 接触片及接收口背衬；44 键逐一验证只动 cap/plunger、固定件保持、多源取消、归位和实际可见 plunger 命中；RGB 外驱无回声；两个入口完整配置与四类按压中间态的去墨物理不变；变换父级下四芯插接、邻分支隔离和 3326 个资源释放。当前 `modeled / visual-only`，未做 GPU/浏览器、量产配合或实体硬件验收，未实现键盘、电气或固件运行。
