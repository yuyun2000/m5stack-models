# Unit Ultrasonic-IO U098-B2

本款是GPIO接口的RCWL-9620 Unit，使用自己的官方结构与图库。坐标+X向右、+Y朝上方发射探头、+Z朝探头。保留自身原装rear1共3044面、front2共2466面，合计5510面；仅作共同平移，不借B1的装配或印刷，不缩放、拉壳、补面或删面。原壳24.02794×56.02794×9mm公差保持，含探头完整包络深度15.2mm另列。所有原面逐面有向顶点对应，最大浮点误差小于0.000001mm。

本款自己的裸板照片与资料确认GPIO载体、RCWL-9620、黑色Grove及两枚16mm探头。板材、RCWL-9620的16个引脚、可见阻容与支持器件、焊盘/通孔及固定孔均为实体。隐藏安装位置、板厚和封装细节为明确的外观推导。原壳安装孔中段实际半径2.425mm，保留原生分层孔口与后侧外向开口；不声称统一Ø5的生产孔。

两个黑色探头各有实体厚壁与上沿、54根实体网栅、真实方孔和网厚、深处静态银色膜片/中心凸台、支撑环/三根支柱、封闭底及两个进入PCB的金属脚。网下到已测膜片背挡有6.5–7.15mm真实深度。网格孔和壁不是PNG，内部膜片不运动；这些载体仅是被动几何元数据，不注册距离数值、声波、触发回波、传感器或关节行为。网距/线宽/内部支撑安装由本款照片推导，不能作为生产尺寸。

唯一实际组件为`grove`，四针标签依本款清晰照片为GND、5V、TRIG、ECHO，背标为PORT.B.I/O。当前官方表格中的PORT.A/SDA/SCL冲突已有反馈（编号588c2040ad754aab8e946edc4cbd033d），未重复提交。模型不据印刷标签模拟供电、距离或GPIO时序。

`Model`与`GroveModule`两入口；后者具有既有真实四芯线、`unitFrame`外驱姿态和独立`cable`。默认`rearCover:true`；`rearCover:false`精确移除真实后壳、背标物理薄膜/墨层与单颗固定件的头、盲孔底、杆共三个mesh，其他全部实体属性、索引和世界矩阵保持。没有虚构按钮、LED或机身活动关节。

背面使用经本款型号/类别和实物官图核对的原始转曲矢量，按真实16×36mm本体版面直接生成1600×3600普通PNG；字符轮廓完整保留，不重画字体、不裁产品照片。包装标题被排除。前面没有胶贴，也不以贴图补实体。公开仅最终PNG，源矢量/私有映射/文件名/URL/转换和证明中间件均不分发。`artwork:false`只关闭墨层；两入口、两种后盖配置全部保持实体不变。图片静态URL字面量已做真实加载派发检查，实际Vite资源由集成统一验证。
