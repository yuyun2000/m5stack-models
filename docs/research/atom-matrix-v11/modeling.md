# Atom Matrix v1.1 · C008-B-V11

这是独立登记的 BMI270 修订款，不是原 C008-B / MPU6886 的标签变体。当前官方规格为 ESP32-PICO-D4、4 MB Flash、BMI270、25 颗 RGB、用户键、Reset、IR、USB-C、Grove 和 5/4 孔后排母。只注册两个真实按键、25 个独立外部 RGB 和四个机械接口；IMU、红外、总线及固件由下游负责，不制造传感数值。

本款自身 Hardware 路径提供的 STL 与原版 Matrix 路径确为同一 Git blob。已下载本款自己的原文件，逐顶点、存储 normal、attribute word 和源面 ID 与本款运行时对照。全源 6,028 面中保留实际前后壳 3,014 面，另 3,014 面为重复装配预览；`duplicate-preview-map.json` 完整记录匹配和微小源法线差异。没有以文件相同来推定两款电子、印刷和元件相同。当前产品表名义厚度 13.9 mm、自身 CAD 为约 13.8 mm，保留冲突而不缩放原网格。

共用已验证的几何/输入算法，但本款入口、原生数据来源、BMI270 灯板实体、尺寸、能力、贴纸和专项均独立。25 颗真实封装、光学面和灯板固定；只有带真实厚度的压力窗与其偏置压杆按下。Reset 是自身原生后壳 U 槽隔离的完整弹舌，包含内外壁和抬起端，固定根、壳、接口和 PCB 不动。部分/全按后取消能恢复原 position/normal 原字节。两个估计行程均为 0.14 mm。

自身官方后视照片清楚显示黄色 M2 圆标被完整贴膜覆盖，因此默认物件包含跨过原生孔的真实薄膜，膜后仍保留原生孔壁、承托管和实际盲止挡。`labelPierced:true` 表示安装前已穿透这片薄膜，才开放 M2 安装孔；这项物理准备独立于 `artwork:false`。不会为去墨删掉膜、壳或盲孔，也不使用黑平面遮空腔。

USB-C 的 24 接点/焊尾/保持、Grove 四接点/键位/深止挡和九个独立排母孔/弹片/深底均为实体。BMI270 按当前灯板原理图放在固定 LED 子板下，隐藏封装尺寸、板级支持、接口深层、光学压力窗机构和行程仍为外观推导，不是制造或隐藏 BOM 验证。

两张批准普通平面 PNG 为本款 BMI270/v1.1 背标和认证标，从完整平面版式提取完整标签并去掉旁边的版式说明；没有使用产品照片像素。认证标按原图比例放在本款原生标贴凹面，九条首交射线确认载体可见。保留原像素分辨率，不声称高精度矢量。私 CSV、原名、URL、矢量和转换器均不公开。

专项 `node scripts/check-atom-matrix-v11-controller.mjs` 直接导入本款实际 Model，覆盖源字节、实体闭合和正体积、真实内壁/接点/M2止挡、两键多源/取消/定时/同时操作、原生弹舌内外壁、九点压力窗运动和固定25灯、独立 RGB/无回声、HUB 与 Button/Encoder/OLED 实际连接、拆接/变父及去墨全部实体不变量。CLI 有 guard、import 不自动运行。模型阶段为 `modeled`；GPU、真实网页拾取、多视图、实物、电气和制造验收另行进行。
