# 原 Atom Matrix C008-B

本款为 ESP32-PICO-D4、MPU6886、25 颗 WS2812C 2020 的原版 C008-B。当前官方 24×24×13.8 mm 与历史 24×24×14 mm 分别记录。没有把 V1.1 的电路、IMU 或贴纸混用。

原生 STL 的 6028 面由两件真实完整半壳 3014 面，以及 3014 面重复装配预览构成。保留后壳 1400 面和前壳 1614 面，不把重复预览当作第三层外壳。运行时每半壳 positions、normals、index、sourceFaceIndex、sourceAttributeWord 均保留冻结数组，使用 Object3D 平移装配；未重网格、缩放或裁去实际壳面。MIT 原生许可全文保留在 native-data.js 和 sources.json。

主矩阵采用实体深色透明丙烯酸压力窗、固定 5×5 LED 子板和 25 个独立 LED 实体。主键压力杆布置在格间，避开 25 条正面光路，进入带径向和底部间隙的真实盲孔开关壳。侧 Reset 从本款源面 2701 沿共享坐标图提取 U 槽内连通舌片：102 个唯一顶点、601 个属性顶点，内壁源面 2162/2164、凹面 2701/2707 和抬高自由端 2672/2687 一并随动。原生根部世界 Z=-5.2 mm 固定，自由端 Z=2.56527 mm；槽外固定壳不动。恢复时源位置及法线数组精确还原；透明命中代理不计物理实体，没有增加可见按钮帽遮盖原生面。内置从动杆按原生内壁实际源三角的重心权重运动，进入实体开孔固定承托座，承托座经实体支脚接到主 PCB；保留真实内壁、侧向和深止挡正间隙。两键 .14 mm 视觉行程、柔性规律、内部动作及尺寸均属推导，非测量力学阈值；longPressMs=0，不模拟重启。

背面 5+4 针排母保留原孔壁关系并补齐 9 个真实深井、底止挡、18 个弹片和承接 PCB 的尾针；USB-C 补齐实体金属外壁、舌片、24 个独立触点、24 个后端子和保持片；Grove 有实体四壁、深止挡、4 金属触点、折弯尾针和锁位。M2 孔带真实内壁盲安装管与底止挡。IR 被动树脂体位于 x=-7、+Y 侧原生小开口后方，不作为人眼可见输出。侧面 4/10 个穿孔保留原生壳壁与内部实体，没有用贴图填孔。

PCB 轮廓与安装 Z、LED 板厚度及支柱、芯片位置、连接器内部尺寸、舌片和保持结构、安装管、隐藏 BOM、配合与主键支撑均为受原生壳和官图约束的外观推导。缺少原版完整量产装配 STEP/BOM，不能作为生产配合或电气认证依据。MPU6886/ESP32/IR 仅被动物理外观；未注册 Display、传感器、IMU、音频、固件、I2C/UART/USB 协议、供电或复位行为。

贴纸按本款官方图片重新绘制成 2 张高清普通 PNG，保留可辨引脚、MPU6886、按钮/LED/IR 标记与侧面产品名和认证符号。不可辨个体编号和微字省略，原始表格、私有矢量与生成器不进入公开仓库。背贴投影只取实体承印面，M2 真孔保持开放；侧贴载体避开 IR 原生小开口。关闭 artwork 只去墨，物理载体始终存在。

`smoke.json` 保留首版历史收据；它未检查原生按钮中心的实际位移，不能单独证明此次 Reset 修订。当前修订专项见 `reset-amendment.json`：250 个物理 Mesh、20514 面全部闭合有向 degree2、正体积且 FrontSide；原生全部静止数组与源哈希精确。对已报缺陷中心、凹面几何中心、原生内壁和抬高自由端做真实 FrontSide 射线，验证部分/完整行程的 +X 位移、精确回弹；逐属性验证全部固定点、其它实体、接口框架和 LED 板不动。内置从动杆相对原生内壁间隙约 .04236 mm，载体孔内 Y/Z 两向间隙各 .15 mm，深止挡全按时仍大于 .349 mm；这些值描述受壳体约束的外观配合，不是量产规格。

专项同时保留两键独立多源、取消和实际 timer 清理；25 LED 独立材质和指令；9 井轴向深底及 36 条真实内壁射线，USB/Grove/M2/IR/25 光路检查。真实 HUB 下连接 Button、Encoder、OLED，验证完整子事件路径、独立 framebuffer、主机/邻件隔离、四芯电缆、拆接与变父。artwork on/off 在静止、两键部分/全按与已连接状态下所有物理属性、index 和世界变换严格一致。两张 PNG、原生 sourceFaceIndex/sourceAttributeWord 和公开 API 均保持原值。浏览器整模视觉验收由根集成阶段完成，此作者只交 work 候选及 source overlay 专项，未声称 outputs 已应用。
