# Basic v2.7 / K001-V27

本款是独立的 ESP32 主机，实现自身默认装配、真实输入件的形状与运动、外部像素和 Grove 机械连接。不是 Core2、CoreS3 或旧 Basic 的换名。当前阶段为 `modeled`；CPU 几何和 API 通过不代表 GPU、多视图、制造、电气或实物验证。

## 身份和来源

官方产品页确认 K001-V27、ESP32-D0WDQ6-V3、16 MB Flash、2.0 英寸 320×240 ILI9342C、CH9102F、三个正面物理键、左侧 Power/Reset、底部电源拨钮、USB-C、microSD、红色 Port A 和 110 mAh 电池。产品页关联的 2017 年电路图与当前芯片/Flash/USB 版本不同，不用旧图推定 v2.7 隐藏 BOM。

名义尺寸表为 54×54×17 mm，首图 caption 写 18 mm，包装图写 17.5 mm。固定 commit 的自身 CAD 四件参考包络为约 54.192511×54.000004×17.000000 mm，左侧电源帽突出于 54 mm 本体；保留原尺寸，不通过缩放消除冲突。运行时增加玻璃、真实贴纸薄载体及后拨钮握纹后，包络另见 `sources.json`。坐标为 +X 右、+Y 上、+Z 屏幕；原 CAD `(x,y,z)` 经刚性旋转和位移变为 `(x,-z,y+0.2)`。

## 混合几何路线和逐面账

自身 Middle Frame STL 的 10,810 面、Front Button STL 的 2,484 面及 Side Button STL 的 2,372 面均为有向闭合、正体积网格。本款只发布派生运行时数组，原文件留在工作资料区。`native-map.json` 按 SHA-256 记账：原 position、存储 normal、attribute word 和源面 ID 均保留；index 为不合并原顶点的 Uint32 顺序索引。运行时不重算法线、不改数组或拓扑，只应用刚性装配和按压变换。

供应文件只有一个正面帽。自身照片确认三个相同帽，故 A 使用原位置，B/C 沿 X 分别刚性平移 12/24 mm。连同框和侧键，运行时共 5 个原生实例、20,634 实例面，唯一源面 15,666。三只前帽的原始属性字节相同，不虚构三个独立源文件。

自身 Bottom Shell OBJ 的 17,639 面仅作本款外形、侧开口及固定孔参考，运行时保留面数 **0**。该源有 537 条单边，集中在背面凸字的两个深度，且缺少自身照片清楚可见的底部拨钮孔。它不能直接冒称完整新版后壳。运行时后壳独立原创重建，包含四边真实针井窗口、四个软脚嵌孔、两个阶梯固定孔、真实拨钮开口、厚壁、深止挡、承托 PCB、电池外形和接点。背部模压品牌线条/字样为可辨内容的独立几何近似，不是原厂 logo 矢量或原面保源。

前盖玻璃和显示光学基底按本款照片重建；三个键孔真正切穿玻璃周边。主 PCB、LCD 承托、固定件、接口深层、扬声器封装/声道、薄膜及电池尺寸为外观推导，不是完整隐藏 BOM。

## 按压、拨钮和显示

- `a`、`b`、`c` 是原生刚性帽，沿 -Z 内收 0.30 mm；`power` 为自身原生侧帽，沿 +X 内收 0.25 mm。行程是明确的外观估计，固定框、PCB、玻璃和接口不动。
- `power-switch` 只在安装底座时出现。它复用 `Button` 的 latching 语义，两个稳定位置 `0/1`，实际沿 +Y 相差 2.8 mm，默认机械位置为 `1`。`press/release` 改变物理档位，取消不产生 click；`setPosition()` 是无输入回声的外部状态命令。以上均不执行电源、复位或固件逻辑。
- `lcd` 是外部 320×240 framebuffer，无触摸能力。有效区按 2 英寸 4:3 对角线推导为 40.64×30.48 mm，注册位置来自本款照片，等待面板机械图。按键不改屏幕，电源键不清屏，显示不自动播放工厂程序。

## 接口与拆底形态

USB-C、红色 Grove 和 microSD 的口面，以本款原生框真实开口锁定：USB `[-27,0,0.75]`，Grove `[-27,-14,-0.3]`，SD `[-6.5,-27,0.7]`。microSD 口位于正面下边的偏左位置，不能按泛用模板放在正中央。各口包含厚壁、舌/卡导向、实际接点、深止挡和板级承托；未默认放入卡或线。

`mbus` 提供自身后部 2×15 排母的真实孔、四壁、60 片凹入弹片及 30 个独立深止挡。默认完整电池底座遮住主机 M-Bus，并有 30 根真实机械配合针。`base:'removed'` 显示拆下底座后的主机后 PCB、标签和 M-Bus，底座整件省略，不把它假装成可电气仿真的 module。已安装底座的四边 15/15/8/8 孔和凹入接点另作外观结构，不注册未经实现的额外总线行为。

所有接口、管脚文本都是机械外观/标注；GPIO、I2C、USB、存储、扬声器、电池和开关电气行为由下游实现。无虚构 sensor、LED、IMU 或 speaker 组件。

## 贴纸

本款使用用户批准的普通平面栅格，公开只含 7 张 PNG。四条后壳管脚条和 PCB pinmap 共 5 片实际安装；拆底配置剩 PCB 1 片。另两张 compliance/care 栅格来源已确认，但自身照片未定位，暂不凭空贴到可能有孔的侧面。

PNG 保留批准平面图片的原有像素分辨率；不是矢量渲染或高分辨率重绘，也不是产品照片裁片。公开图片从完整平面标签提取完整 panel 并以无元数据 RGB PNG 编码。四条后部薄膜和 PCB 标签的实体载体独立保留，`artwork:false` 只去墨。私表、矢量、源名称、源 URL、映射和转换程序不分发。

## 当前验收边界

`node scripts/check-basic-v27-controller.mjs` 直接导入本款实际 `Model`。专项覆盖两配置真实实体闭合/FrontSide/正体积、源属性字节、30 主孔与 46 边孔、304 条四壁射线、USB 24 接点、Grove 4 接点、SD 8 接点和真实口位；72 条原生内外表面采样及 2 固定邻区，在 rest/partial/full/returned 四态比对；多源保持、取消、真实 click timer、实体全回位和稳定拨钮；RGBA/RGB565/独立 peer/无回声；Grove HUB→Button/Fan 实际线芯、两端插头、转动、变父与拆装；全部实体去墨不变量及 905 个实际资源各释放一次。专项可 import，CLI 有 guard。

后续根接入还需目录/导出、共享主机与线缆检查、构建与真实浏览器输入和外观验收。CPU 三角预览只帮助检查形状，不能替代 GPU 视觉证明。
